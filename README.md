## 👋 Sobre mim

Sou estudante de Sistemas de Informação na PUCPR, no 4º período, em Curitiba.

Comecei a programar porque queria entender como as coisas funcionam por dentro — e descobri que gosto mais ainda de construí-las. Hoje meu foco é back-end: modelar o banco, subir a API, fazer rodar em container. Cada repositório aqui é uma etapa desse caminho, não um portfólio de coisa pronta.
